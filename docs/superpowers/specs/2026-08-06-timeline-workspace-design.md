# 关系演化时间线工作区视觉统一设计

## 目标

将“关系演化时间线”调整为与“IP 关系全景”一致的工作区视觉模式，同时保持现有关系轨迹数据、出现次数筛选、章节筛选和人物点击行为不变。

## 交互边界

- 时间线仍通过左侧抽屉打开和关闭。
- 抽屉内部采用“标题栏 → 工具栏 → 内容区”的层级，与 IP 关系全景保持一致。
- 折叠仅隐藏时间线内容区，标题栏和展开入口保留。
- 全屏作用于整个时间线工作区，进入全屏后仍可退出并恢复原状态。
- 删除嵌套组件中的重复标题、全屏和折叠操作，避免同一功能出现两套控件。
- 不改变现有 `viewMode`、章节筛选、关系轨迹排序、最多展示 200 条及节点选择逻辑。

## 视觉结构

1. 抽屉标题栏：保留“关系演化时间线”和关闭按钮。
2. 时间线工作区标题栏：显示项目名、当前章节语境、最近更新时间及折叠/全屏操作。
3. 时间线工具栏：沿用现有出现次数筛选和章节筛选，使用 IP 关系全景的分段按钮与间距。
4. 内容区：保留空状态提示和关系轨迹列表，使用与图谱工作区一致的表面、边框、滚动和留白。

## 验收标准

- 页面中时间线不再出现重复的标题、折叠或全屏按钮。
- 点击折叠后只隐藏内容，点击展开可恢复。
- 点击全屏后整个时间线工作区进入全屏，Esc 或按钮可退出。
- 现有时间线筛选和节点点击测试不回归。
- 前端构建成功。
